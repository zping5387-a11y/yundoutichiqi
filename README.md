# 芸豆提词器（教学版）· VC/MFC

一个用 **Visual C++ / MFC** 开发的教学提词软件。专为"一边讲课、一边看稿"的场景设计：

- **私密芸豆提词**：提词浮层不进任务栏、不抢焦点、鼠标点击默认可穿透（**可选**：面板「④ 浮层控制」
  里取消「鼠标穿透」后，浮层上可直接用滚轮 / 点击），并通过
  `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 在**录屏、屏幕共享、截图中完全不可见**——
  你能看见提词，学生看到的共享画面里什么都没有。
- **语音跟读**：默认用内置离线识别（sherpa-onnx + 中文 Zipformer xlarge 模型，识别率远高于系统自带），也可切换系统引擎；你念到哪里，提词器就自动滚到哪里；
  识别文本与讲稿做归一化后**精确匹配**（严格子串查找，逐字一致才定位），
  句中个别同音错字时改用句尾整块文字精确对位；支持跳读、重复念。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 稿件载入 | 点「添加稿件」加入 txt/md/srt、**Word（.docx）/ PPT（.pptx）**、从剪贴板粘贴、直接拖拽 txt/docx/pptx 到窗口，内置示例讲稿。Office 文档不解包依赖 Office：程序直接读 OOXML 包（zip）里的正文 XML——Word 取 `word/document.xml`（`<w:t>` 文本、`<w:p>` 分段、表格单元格成行、修订删除与 mc:Fallback 副本自动跳过），PPT 按**页码顺序**拼接 `ppt/slides/slideN.xml`（`<a:t>` 文本，页与页之间空一行，备注页不读）；加密/损坏/旧版 .doc/.ppt 会给出中文提示，请另存为 .docx/.pptx |
| 主控制面板 | 左侧竖排**四个页签：「稿件」**（打开/剪贴板/示例 + 最近文稿列表，双击即载入）、**「语音」**（跟读/命令、语言与引擎、麦克风与输入电平）、**「设置」**（显示调节 / 浮层控制 / 说明）和**「关于」**（版本说明 + **作者邮箱**：显示邮箱地址（可点击，直接用系统邮件客户端写信）、点「复制邮箱」一键复制，程序目录放了 `contact.png` 还会显示二维码，没有就显示占位提示）。窗口为**无边框样式**（WS_POPUP，无系统标题栏/边框）：按住顶部 44 逻辑像素的标题带可拖动窗口（支持双击最大化 / Aero Snap），边缘 6 逻辑像素可拉伸调大小、可最大化（自动避开任务栏），右上角自绘「最小化 / 最大化 / 关闭」三个按钮（**最小化和关闭都等于把面板收进托盘**：窗口隐藏、浮层和语音跟读照常工作，`Ctrl+Alt+M` 或托盘图标随时叫回来；真退出用面板里的「退出」、托盘右键菜单或 `Ctrl+Alt+Q`）。拉宽时整行控件跟着伸展、底部按钮钉在窗口下缘，小于设计尺寸会被自动限制 | 
| 半透明浮层 | 逐像素透明（GDI+ 渲染 + `UpdateLayeredWindow`），不透明度可调 |
| 鼠标穿透（可选） | 默认锁定态完全穿透（`WS_EX_TRANSPARENT`），不挡下层 PPT / 白板的点击；面板「④ 浮层控制」的「鼠标穿透」复选框可关闭，关闭后浮层接收鼠标：**滚轮直接滚动，按住拖动 = 拖动内容（1:1 跟手，上下箭头光标提示）**，位置移动仍走「调整位置」。设置存于 INI `[view] clickThrough` |
| 逐字高亮 | 已读文字变高亮色、当前字带实底块（精确到单字边界）+ 左侧色条 + 底部进度条，上下边缘渐隐 |
| 语音跟读 | WASAPI 自采集（可选麦克风、实时电平）→ 离线识别（sherpa-onnx，默认）或系统听写 → 精确子串匹配定位；匹配度实时显示 |
| 智能跟随（AI 语音跟随） | 跟读时**读到哪滚到哪、停读就暂停**，速度不用手动调：目标位置按「读到第几个字」连续推导（含行内进度），比例控制 + 加速度限幅平滑逼近；麦克风静音 0.6s（识别延迟另有 1.2s 宽限）即刹停，继续念自动续上。关掉 `[speech] smartFollow` 可退回按行跳动的旧行为 |
| 浮层顶部按钮条 | **鼠标悬停在浮层上时自动显现，离开约半秒后自动隐藏**（锁定穿透态靠轮询光标位置判断，一样有效）。一排按钮：**返回页首 / 到页尾 / 滚动 / 停止滚动 / 切换稿件**。「返回页首/到页尾」会把跟读位置一并带过去，念哪句就从哪句继续匹配；「滚动/停止滚动」控制自动滚动（与语音跟读互斥，点「滚动」会先关跟读）。**滚到页尾会自动停止滚动**（等同点了「停止滚动」，「滚动」高亮随之熄灭，不会空转）。**「切换稿件」弹出最近文稿列表**：显示最近打开过的 8 篇（文件名 + 所在文件夹、正在用的打勾、已删除的置灰），点一下即切换，末尾还有「打开其他文稿…」直接弹文件对话框；点列表外面或再点一次按钮就收起。因锁定态浮层点击穿透，按钮条与滚动条一样是独立的分层小窗，锁定时也能点；同样不进录屏 / 共享画面 |
| 语音命令 | 说「下一页 / 上一页」整页翻（留一行重叠），「回到顶部」回开头；只认句尾命令词、正文不误触发。**与语音跟读完全独立**：各有开关/热键（`Ctrl+Alt+V` / `Ctrl+Alt+C`），只开命令也能翻页，只开跟读不会执行命令；内部共用同一路麦克风与识别引擎，任一打开即启动识别，两个都关才停止采集 |
| 自动滚动 | 无语音环境时的兜底模式，1~10 级速度；到页尾自动停 |
| 显示调节 | 字号、行距、文字/高亮颜色、阴影描边、文字镜像（反射玻璃提词） |
| 位置与大小调整 | 「调整位置」模式下：拖动内部移动、拖动边缘/四角缩放；也可用「宽 −/＋」「高 −/＋」按钮或热键微调；一键铺满/重置；位置和尺寸自动记忆 |
| 关于页（作者邮箱） | 左侧第四个页签「关于」：版本说明 + **作者邮箱**（大字链接色显示，**点一下就用系统默认邮件客户端开一封新信**（`mailto:`，打不开时自动退回复制）；点「复制邮箱」直接进剪贴板，按钮会闪一下「已复制 ✓」）。二维码位置默认是占位框——把一张 **`contact.png` 放到 exe 同目录**，重启后这里就等比显示成二维码。邮箱地址可在 INI 的 `[about] email=` 里改（不写就用内置默认值），改完重启生效 |
| 配置持久化 | 设置保存在 INI（exe 目录或 `%APPDATA%\TeacherPrompter`）。**INI 的 `[file]` 段是用户手写的稿件定义，程序只读、永不写回**：`lastScript` 被当作启动时要打开的稿件，`recent0..7` 作为「切换稿件」列表里的预设清单；切换稿件 / 双击最近文稿等操作不会改动它。程序自己的「上次打开 / 最近文稿」记录单独存于 `%APPDATA%\TeacherPrompter\recent.ini`（可用环境变量 `TP_DATA_DIR` 改目录），与 INI 中的定义互不干扰 |

## 运行

双击 `build\TeacherPrompter.exe`（x64，已静态链接 MFC 与 CRT，无需安装运行库，Win10 2004+ / Win11）。
发布包见 `output\`（`tools\make_release.py` 生成）：**安装包不含语音模型**，只有 24MB，
第一次用跟读时按需下载（见下）。

**典型上课流程**

1. 点「添加稿件」选一篇讲稿（或复制教案后点「从剪贴板」）。
2. 调整浮层位置和大小：点「调整位置」→ 拖动内部移动、拖边缘或四角缩放（或用「宽 −/＋」「高 −/＋」按钮）→ 「完成锁定」。
3. 进入腾讯会议/钉钉等开始共享屏幕——共享画面里**看不到**提词浮层。
4. 需要一个干净桌面时按 `Ctrl+Alt+M` 隐藏控制面板（隐藏后托盘区会有一个
   蓝色「T」图标：双击恢复面板、右键有浮层/跟读/退出菜单），再按 `Ctrl+Alt+M` 随时找回面板。
5. 点「开始跟读」（或 `Ctrl+Alt+V`），正常讲课即可，念到哪里滚到哪里。

## 语音跟读：识别引擎

- **离线识别（默认）**：sherpa-onnx 流式 Zipformer 中文 xlarge 模型（int8，下载约 740MB），
  纯本地运行、识别时不联网。中文识别准确率显著高于系统自带引擎。
  需要与 exe 同目录放置 `sherpa-onnx-c-api.dll`、`onnxruntime.dll`、`onnxruntime_providers_shared.dll`。
- **系统识别**：Windows 自带 SAPI 听写，兼容兜底（准确率较低）；选英语时自动用它。

### 模型按需下载（发布包不再内置）

模型不随安装包发布，第一次要用跟读时程序自己下：

- 点「开始跟读」，或在「语音」页点状态行的「点这里下载」→ 确认后后台下载，下完自动启用。
- **默认按文件从 HF 镜像取**（`hf-mirror.com`，不通再退 `huggingface.co`），逐文件写
  `models\<模型名>\<文件名>.part`，校验字节数后改名 —— 断了只重传当前文件，
  已存在的文件直接跳过，重装/修复都很快。
- 下载中状态行显示百分比 / 速度 / 剩余时间，点它可以暂停，下次接着下（`.part` 保留）。
- 安装位置：能写就用 `<程序目录>\models\`（便携，连模型一起拷走就能离线用），
  程序目录只读时退到 `%APPDATA%\TeacherPrompter\models\`；两处都在 `FindModelDir()` 的搜索路径里。
- 换源：
  - `TP_MODEL_MIRROR` → 逐文件通道的自建源（目录地址，程序在后面拼文件名，例如
    `https://内网/models`），设了它就只用这一个源，且不校验文件大小；
  - `TP_MODEL_URL` → 回到「整包 tar.bz2」通道（官方 GitHub release 或你自己的单文件镜像）。
- 代理：只有代理能出网的机器设 `TP_MODEL_PROXY=http://127.0.0.1:7890`
  （也认标准的 `HTTPS_PROXY` / `HTTP_PROXY`）。程序按「显式代理 → 系统代理 → 直连」
  依次尝试，前一种不通会自动换下一种，不用手工改配置。
- 也可以手工把 `models\sherpa-onnx-streaming-zipformer-zh-xlarge-int8-2025-06-30\`
  整个目录拷到程序旁边，效果一样。

> 为什么不用 GitHub 那个 570MB 的 tar.bz2 了：国内下载经常被代理/网络掐断，一个字节不对
> 整包作废，还要再赌一次 bz2 解压（表现就是「安装包不完整」）。逐文件下载没有这个风险，
> 也不需要 `tar.exe`。

## 语音跟读：麦克风怎么选（重要）

**程序不再依赖 SAPI 的默认输入设备**，而是自己用 WASAPI 共享模式采集，原因是一次真实故障：

> 系统「默认录音设备」是显示器/音箱自带的麦克风（`麦克风 (HECATE G1500 BAR)`），
> 而会议软件用的是「默认**通信**设备」（`麦克风 (USB Microphone)`）。
> SAPI 只认前者 → 识别器启动成功但收到的是静音 → 表现为「点了开始跟读完全没反应」。

所以面板「② 语音跟读」里新增了**麦克风下拉框**和**实时电平条**：

- 下拉框默认「自动（优先默认通信设备）」，即会议软件正在用的那个麦克风；也可以手动指定。
- 电平条 `▮▮▮▯▯▯▯▯▯▯▯▯ 42%` 会随说话跳动：**说话时电平不动 = 选错设备或麦克风静音**，
  此时状态栏会直接提示「没有收到任何音频信号：请在上方麦克风下拉里换一个设备」。
- 运行中切换麦克风会自动重启识别，无需手动停止。
- 自己采集的好处：可与腾讯会议/钉钉**同时**使用麦克风（共享模式），不再被会议软件挤掉。

## 语音跟读要求与排查

- 需要系统安装语音识别语言包：**设置 → 时间和语言 → 语音** → 添加「中文(简体，中国)」。
- 麦克风权限：**设置 → 隐私和安全性 → 麦克风** → 允许桌面应用访问。
- 状态栏含义：
  - 「跟读中 · 引擎名 · 输入：麦克风名」→ 识别引擎已就绪，正常说话即可；
  - 「检测到声音，正在识别…」→ 麦克风有输入，等待识别结果（1~2 秒延迟属正常）；
  - 「没有收到任何音频信号…」→ 电平长期为 0，换一个麦克风；
  - 「跟读中 · 匹配度 x% · 已到第 n / m 字」→ 已定位到稿件第 n 个字，浮层随之滚动。
- 若提示启动失败，错误码含义：`0x80070057` 听写语法不支持（程序会自动重试静态语法）、
  `0x8004503A` 类错误多为无可用识别器（需安装语音包）。
- 若提示识别引擎不可用，可先用 `Ctrl+Alt+P` 自动滚动模式兜底。

**自检模式**（无需对着麦克风说话即可验证整条链路）：

```bat
set TP_SPEECH_WAV=某个16kHz的wav文件路径
build\TeacherPrompter.exe
```

程序会把该 wav 当作麦克风输入，若状态栏出现「匹配度 … 已到第 n 字」且浮层滚动，
说明识别 → 匹配 → 滚动链路正常（`tools\genwav.cpp` 可用中文 TTS 合成测试音频）。

**回环自检**（连麦克风都不需要，验证"采集 → 识别"这段）：

```bat
set TP_MIC_LOOPBACK=1
build\TeacherPrompter.exe
```

此时程序抓取「扬声器回环」而不是麦克风，用播放器放一段中文语音，电平条与识别结果都应有反应。

## 从源码构建

**方式一：Visual Studio（推荐）**

用 VS2022 打开 `TeacherPrompter.sln`，选择 `Release | x64`，直接 F7 构建。
配置为**静态 MFC + 静态 CRT**，产物可直接拷贝到其他机器运行。

**方式二：命令行（无需打开 VS）**

```bat
tools\build_cl.bat     :: 输出 build\TeacherPrompter.exe
```

要求：VS2022（含"适用于最新 v143 生成工具的 C++ MFC"组件）+ Windows 11 SDK 10.0.26100。
如版本不同，请修改脚本顶部的 `MSVCVER` / `SDKVER`。

## 技术要点（"隐形"是怎么做到的）

1. **点击穿透**：`WS_EX_TRANSPARENT`，鼠标事件直接落到下层窗口，不挡 PPT 操作。
2. **不留痕迹**：`WS_EX_TOOLWINDOW`（不在任务栏/Alt+Tab）+ `WS_EX_NOACTIVATE`（永不抢焦点）。
3. **防录屏**：`SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`，
   DWM 在所有采集路径（OBS/会议软件共享/PrintScreen 等）中都跳过该窗口；
   本机屏幕上你依然看得见。
4. **透明渲染**：GDI+ 画到 32bpp ARGB 内存位图 → 边缘渐隐 + 预乘 alpha →
   `UpdateLayeredWindow` 呈现，文字抗锯齿清晰。

> 调试提示：设置环境变量 `TP_CAPTURE_ALLOWED=1` 可临时关闭防录屏保护，便于截图排查渲染问题。

## 已知限制

- PPT **全屏放映**（独占全屏窗口）可能盖住置顶浮层，建议使用"窗口化放映/演示者视图"，
  或双屏（提词器放在副屏）。普通窗口、浏览器、白板软件均正常置顶。
- 语音听写依赖 Windows 语音识别语言包，识别速度受机器性能影响；长句识别约 0.5~1 秒延迟。
- Win10 2004 以下系统不支持"防录屏"，浮层会被录进画面（程序会自动降级为普通置顶）。
